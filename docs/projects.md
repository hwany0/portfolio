# 주요 프로젝트

## 1. 모바일 수금관리 재구축 프로젝트
- 기간: 2019.08 ~ 2019.11
- 역할: 풀스택 개발, 화면 개발, 결제 연동, 운영 보완
- 기술 스택: Java 7, Spring Framework 4.2.1, JSP, MSSQL, Android, WebView
- 설명:
  - 기존 APP 개발 업체 도산으로 유지보수가 어려워진 모바일 수금관리 시스템을 하이브리드 웹앱 기반으로 재구축
  - APP + WEB 구조로 전환하고, 카드 결제 연동, 결제 상태 관리, 결제 누락 방어 기능을 구현
  - 반복적이고 수기 처리되던 결제 보완 업무를 자동화하여 운영 부담을 완화
- 성과:
  - 유지보수성과 모바일 업무 편의성 향상
  - 결제 상태 누락 대응 체계 강화
  - 운영 효율성 개선

## 2. 모바일 수금관리 기능 고도화 프로젝트
- 기간: 2021.01 ~ 2021.04
- 역할: 풀스택 개발, 화면 개발, 모바일 푸시 기능 개발
- 기술 스택: Java 7, Spring Framework 4.2.1, JSP, MSSQL, Firebase FCM
- 설명:

  - 모바일 현장 업무를 보조하는 기능을 개발하여 수금/배달 업무의 실시간 가시성을 높임
- 성과:
  - 배달 업무 효율 개선
  - VOC 대응 속도 향상
  - 모바일 업무 환경 개선

  - 비대면 수금 프로세스 실현
  - 업무 자동화 및 운영 부담 감소
  - 외부 API 안정화 및 서비스 연속성 확보

## 5. HLL 통합 멤버십 사이트 구축 프로젝트
- 기간: 2023.06 ~ 2024.01
- 역할: 백엔드 개발, 인증 구조 설계, 포인트/기프트샵 연동, 멀티 데이터소스 설계
- 기술 스택: Java 8, Spring Framework 5.1.7, JSP, MSSQL, MongoDB, Redis, Elasticsearch, nginx, wildfly
- 설명:
  - 매체사별 도메인 분리 환경에서 공통 인증 서버와 연동되는 통합 멤버십 인증 구조 구현
  - iframe 기반 로그인 팝업, postMessage 통신, Redis 기반 토큰 재발급, PASS 본인인증 연동 설계
  - KT 기프트샵 연동 및 포인트 적립/차감 로직 개발, MongoDB 이력 관리와 RDB 정합성 유지
- 성과:
  - 다양한 매체사 도메인 환경에서도 일관된 인증 경험 제공
  - 포인트 처리의 신뢰성과 데이터 정합성 강화
  - 회원 인증 및 멤버십 서비스 확장성 확보

## 7. 방송 광고 관리 시스템 재구축 프로젝트
- 기간: 2025.02 ~ 2025.12
- 역할: 레거시 전환, 공통 UI 구조 설계, MFA 인증 개선

  - 유지보수성과 확장성 확보
  - 인증 보안성 강화
  - 화면 개발 생산성 향상
