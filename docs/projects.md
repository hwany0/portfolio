## 12. JEUS7A / Miplatform Protocol Adapter 오류 진단 및 대응
- 기간: 2024 ~ 2025
- 역할: 장애 분석, 실험실 테스트 환경 구축, 직렬화 대응
- 기술 스택: Java, JEUS7A, Miplatform, `MciResponse`, `DataSet`, `WebArgumentResolver`, `Protocol Adapter`
- 설명:
  - 운영 환경에서 특정 인물/고객 데이터에 공백 또는 보이지 않는 문자가 포함될 때 `Protocol Adapter` 오류가 발생하는 현상을 재현
  - 로컬 환경과 운영 환경의 차이를 비교하면서, 로컬에서는 재현되지 않는 특이한 환경 의존 문제를 분석
  - 실험실용 테스트 Controller를 구성하고 `Flag` 기반 케이스 분기를 통해 `WEB → JEUS → Service → DB` 흐름에서 어느 단계에서 깨짐이 발생하는지 시나리오별로 확인
  - 기존 로직을 유지한 채 `MciResponse.setList`가 DTO 기반으로 동작할 때 발생하던 직렬화 깨짐을 확인했고, `Map` 기반 변환 구조로 전환 시 문제를 완화하는 결과를 도출
  - `addRowBean` 기반 직렬화는 reflection과 타입 기반 인코딩을 수행해 제어문자, `NBSP`, `ZWSP` 등을 처리하면서 버퍼가 깨지는 특성이 있었고, `addRowMap` 기반 구조는 비교적 안정적으로 동작하는 현상을 확인
  - `DataSet`의 빈 컬럼 처리, 정렬 순서, buffer size, chunk 옵션과의 상호작용까지 함께 점검하며 원인을 정밀하게 축소
- 성과:
  - 운영 환경에서 재현되는 통신 장애를 실험실 환경에서 재현 가능하게 정리
  - 공백/비표준 문자에 의한 직렬화 문제를 검증하고 대응 기준을 마련
  - `Bean` 기반 직렬화와 `Map` 기반 변환 차이를 기준으로 안정화 로직을 설계해 운영 안정성을 확보
  - 응답 데이터 크기와 컬럼 구조 검증을 통해 문제 원인 추적의 신뢰성을 높임

  - 데이터가 비어 있는 `DataSet`에서도 컬럼 구조가 함께 생성되는 문제를 확인하고, 컬럼 정보 생성 조건과 정렬 기준을 보완
- 성과:
  - 비표준 문자로 인한 직렬화 깨짐 가능성을 사전에 차단할 수 있는 기준 마련
  - 응답 데이터 정합성 향상
  - 운영 환경에서 유사한 데이터 인입 발생 시 대응 속도 개선

- 설명:
  - 신미디어 시스템의 `JAMIS` 환경에서 비정상적인 로그인 상태나 미접속 누적 상태로 인한 운영 이슈를 점검
  - `Utils > Reset Login Attempt` 기능을 활용해 사용자의 로그인 시도 상태를 초기화하고, 업무가 정상적으로 재개될 수 있도록 지원

  - 본 기능은 J-Custom의 업무 로직이 아니라 신미디어 시스템의 인증 운영 환경에서 필요한 기능이라는 점을 명확히 분리해 관리
- 성과:
  - 비정상 로그인 상태 복구 속도 향상
  - 사용자 업무 중단 시간 감소
  - 신미디어 운영 안정성 강화

## 16. J-Mobile AI Direct Routing 프로세스 구축
- 기간: 2025.09 ~ 2025.12
- 역할: AI UX 설계, 서버 로직 설계, 파라미터/권한/로깅 구조 설계
- 기술 스택: Java 7, Spring Framework 4.2.1, JSP, WebToB, JEUS, vLLM API, Gemma-4, Speech Recognition, J-Mobile
- 설명:
  - 특정 독자 조회 및 업무 처리를 위해 다단계 메뉴 탐색이 필요했던 J-Mobile 운영 환경을 개선하기 위해 음성 기반 Direct Routing 구조를 설계
  - 플로팅 FAB 버튼을 통해 어느 메뉴에서나 음성 입력에 접근할 수 있도록 UX를 정비하고, 사용자의 음성 명령을 기반으로 메뉴와 파라미터를 자동 추론하도록 구성
  - `VoicePromptGenerator`를 통해 메뉴/파라미터/행위 정보를 LLM 프롬프트에 포함시키고, 필수 파라미터 누락 시 재질문과 파라미터 보완 흐름을 설계
  - `VoiceParamResolver`와 `ParamProvider` 전략 패턴을 적용해 메뉴별 파라미터 변환, 추천 후보 생성, 실제 DB 검증을 분리하고, 검색 결과가 없을 경우 유사 후보를 제안하는 흐름을 구성
  - `MenuPermissionService`로 사용자 권한을 검증하고, `VoiceLogService`에서 비동기 로깅을 통해 운영 로그를 남겨 후속 개선 및 장애 분석에 활용
  - 최종적으로 사용자는 음성으로 특정 고객/독자 조회와 수금, VOC, 상세 조회 등과 같은 업무를 바로 이어갈 수 있도록 설계하여 모바일 업무 처리 시간을 단축
- 성과:
  - 다단계 메뉴 탐색에 따른 사용성 불편 해소
  - 고령 사용자와 반복 업무 사용자 기준 접근성 향상
  - 음성 기반 업무 연속성 확보 및 AI 활용 UX 개선
  - 권한 검증, 추천, 로그 기반 운영 분석 구조를 함께 확보하여 실무 적용 가능성을 높임
