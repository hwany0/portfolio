# 경력 경험

## 콘텐트리중앙 — 풀스택 개발자
- 기간: 2019.06 ~ 현재
- 부서: 미디어개발팀
- 주요 역할: 고객관리/수금/결제 시스템 개발, 운영 안정화, 레거시 전환, 인증/보안, 배치 자동화, 공통 UI/기술 대응

### 담당 업무
- J-Custom 개발 및 운영
  - 신문 구독에 대한 계약, 청구, 수금, 배달, VOC 등 고객관리 업무를 지원하는 시스템 개발 및 운영
  - 사용자 요구사항 반영, 데이터 정합성 관리, 장애 대응, 운영 개선을 수행
- 신미디어(JAMIS) 운영 및 개선
  - `Utils > Reset Login Attempt` 기능을 정리해 비정상 로그인 상태 복구를 지원
  - `IIS`/`ClickOnce` 환경에서 배포 경로와 권한 문제를 정리하며 운영 안정성을 높임
  - `FarPoint Spread 9` 기반 대용량 조회 화면 응답 속도와 유지보수성을 개선
- J-Mobile 개발 및 운영
  - 방문 수금 업무를 지원하는 하이브리드 웹앱 기반 화면과 결제 연동 로직 개발
  - 고객 검색, 수금, VOC, 배달 현황 관리 기능 구현
  - 모바일 업무의 실시간성과 보안성을 함께 고려해 사용자 접근 제어와 개인정보 보호, AI 기반 Direct Routing UX 개선을 설계
- 비대면 수금/결제 서비스 구축
  - 오픈지로 기반 청구 생성, 납부 링크 발급, 알림톡 발송, 수금 처리 프로세스 구현
  - 카드 결제 데이터 수신 및 내부 정산/수금 처리 흐름을 자동화
- 인증 및 보안 기능 구현
  - 통합 멤버십 인증 구조, iframe/postMessage 기반 로그인 상태 유지, Redis 기반 토큰 재발급 로직 설계
  - 내부·외부 사용자 MFA 인증 흐름 설계 및 적용
- 레거시 전환 및 공통 구조 개선
  - PowerBuilder 기반 시스템을 .NET 기반 구조로 전환
  - eXBuilder 기반 시스템을 JSP/Thymeleaf 기반 구조로 전환
  - 공통 UI 컴포넌트, GridBuilder, Custom Tag, 응답 DTO 및 공통 예외 처리 정비
- AI 활용 UI/UX 개선 사례 공유
  - 사내 업무 시스템에서 AI를 활용해 사용자 흐름과 데이터 구조를 개선하는 사례를 정리하고 내부 공유
  - DB 메타정보, 파라미터 제공 구조, ParamResolver/ParamProvider 기반 흐름 설계를 적용해 화면 이해도와 사용 편의성을 향상
- J-Custom 운영 개선 및 기술 대응 사례
  - 대량 Insert/Update 성능 개선, Buffer Table 기반 처리 개선, ActiveX 지원 종료 대응을 위한 보안/설치 대안 설계
  - 서버 모니터링 구조 정비를 통해 운영 가시성과 장애 대응 능력을 강화
  - 보안, 배포, 성능, 설정 관리 관점을 함께 고려해 운영 안정성을 강화
- .NET 환경 MyBatis / SqlMap 자동 설정 정비
  - .NET 기반 내부 업무 시스템에서 MyBatis(SqlMap) 설정의 중복과 경로 불일치 문제를 정리
  - mapper location, database 연결 정보, SqlMap.config 구조를 표준화하여 환경 일관성을 확보
- KSNET 가상계좌 입금 서버 MSSQL 전환 대응
  - KSNET 가상계좌 입금 서버를 Oracle 기반 구조에서 MSSQL 기반 구조로 전환하는 과정 지원
  - Java 1.8 서버 구조, GitLab 운영 환경, Windows Service(NSSM) 실행 환경 보완
- 운영 안정화 및 유지보수
  - 외부 API 오류 분석, 데이터 불일치 대응, 배치 자동화, 수기 보완 업무 개선을 통해 서비스 품질을 유지
  - 시스템 환경 변화와 기술 종단 대응을 실무적으로 수행하며 유지보수성과 운영 신뢰성을 높임

### 핵심 성과
- 고객관리, 수금, 결제, 인증, 배치, 연동을 아우르는 업무 시스템을 지속적으로 개발하고 운영하며 실무 역량을 축적
- 비대면수금 프로세스와 외부 연동 흐름을 안정적으로 설계해 사업 운영 효율을 개선
- 인증/보안, 데이터 정합성, 운영 이슈 대응 역량을 기반으로 안정적인 서비스 운영을 지원
- 레거시 시스템을 점진적으로 현대 구조로 전환하며 유지보수성과 확장성을 확보
- AI 활용 UX 개선, 기술 종단 대응, 배포/설치 보완 등의 사례를 통해 실무 중심의 기술 대응 역량을 강화

- 내용:
