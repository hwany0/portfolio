# 경력 경험

## 콘텐트리중앙 — 풀스택 개발자
- 기간: 2019.06 ~ 현재
- 부서: 미디어개발팀
- 주요 역할: 시스템 운영, 신규 프로젝트 개발, 외부 API 연동, 인증/보안, 배치 자동화, 레거시 전환

### 담당 업무
- 고객관리 시스템인 J-Custom 개발 및 운영
  - 신문 구독에 대한 계약, 청구, 수금, 배달, VOC 등 전반적인 고객관리 업무 지원
- 모바일 수금관리 시스템 J-Mobile 개발 및 운영
  - 방문 수금 업무를 위한 하이브리드 웹앱 기반 업무 화면과 결제 연동 기능 구현
  - 고객 검색, 수금, VOC, 배달 현황 관리 기능 개발
- 비대면 수금/결제 서비스 구축
  - 오픈지로 기반 청구 생성, 납부 링크 발급, 알림톡 발송, 수금 처리 프로세스 구현
  - 카드 결제 데이터 수신 및 내부 정산/수금 처리 자동화
- 인증 및 보안 기능 구현
  - 통합 멤버십 인증 구조, iframe/postMessage 기반 로그인 상태 유지, JWT/토큰 재발급 로직 설계
  - 내부·외부 사용자 MFA 인증 설계 및 구현
- 레거시 전환 및 공통 구조 개선
  - PowerBuilder 기반 시스템을 .NET, JSP, Thymeleaf 기반 구조로 전환
  - 공통 UI 컴포넌트, GridBuilder, Custom Tag 설계, 공통 예외 처리 및 응답 DTO 정리
- 운영 안정화 및 유지보수
  - 외부 API 오류 분석, 데이터 불일치 대응, 배치 자동화, 수기 보완 업무 개선

### 핵심 성과
- 다양한 고객관리 및 수금 요구 사항을 반영한 시스템을 지속적으로 개발하고 운영하며 업무 효율성을 개선
- 외부 API 연동 및 연계 데이터 처리 흐름을 안정적으로 설계하여 비대면 수금 프로세스 구축
- 보안, 인증, 결제 흐름, 데이터 정합성 영역에서 운영 안정성과 신뢰성을 강화
- 레거시 시스템을 점진적으로 현대 구조로 전환하며 유지보수성과 확장성을 확보
